Facturas

Las rutas de esta página se agregan a la URL base. Abrir un listado de ejemplo.

GET /facturas
Lista y filtra facturas. Devuelve items, pagina, tamanio, totalElementos y totalPaginas.
GET /facturas/{id}
Devuelve la cabecera y los renglones de una factura. Usá el id del listado.
GET /facturas/{id}/pdf
Descarga el comprobante PDF de una factura emitida o anulada.
GET /facturas/reporte
Descarga un reporte con los filtros del listado. Acepta formato=pdf (predeterminado), xlsx (o excel) y txt.
POST /facturas
Crea un borrador. Devuelve 201 Created con la URL del recurso en Location.
PUT /facturas/{id}
Reemplaza la cabecera y todos los renglones de un borrador. Devuelve 200 OK.
PATCH /facturas/{id}/estado
Emite un borrador o anula una factura emitida. Devuelve 200 OK. La emisión asigna el número y un CAE simulado.
DELETE /facturas/{id}
Elimina un borrador. Devuelve 204 No Content.

Filtros y paginación

El listado y el reporte aceptan fechaDesde y fechaHasta con formato AAAA-MM-DD, estado (BORRADOR, EMITIDA o ANULADA), montoMinimo, numero, clienteId e informada (true o false).

El listado también acepta pagina (empieza en 0) y tamanio (10 por defecto, máximo 100).

Catálogos

Cada consulta devuelve opciones con id, etiqueta, valor y codigoMoneda. Los dos últimos campos pueden ser nulos.

  • GET /catalogos/puntos-venta
  • GET /catalogos/clientes admite ?q=texto.
  • GET /catalogos/condiciones-iva
  • GET /catalogos/tipos-moneda
  • GET /catalogos/lista-precio-articulos admite ?q=texto.

Cuerpos JSON

Enviá Content-Type: application/json. Para altas y cambios, X-Usuario indica el usuario de auditoría y es opcional. El encabezado no autentica.

Crear o reemplazar un borrador

Consultá los catálogos para obtener los IDs. clienteId, fechaEmision y observaciones son opcionales. Si omitís la fecha, se usa la del servidor. Se requiere al menos un renglón con cantidad positiva. La bonificación (opcional) debe estar entre 0 y 100. El servidor toma el precio de la lista y calcula los importes.

{
  "clienteId": null,
  "condicionIvaId": 1,
  "puntoVentaId": 1,
  "tipoMonedaId": 1,
  "detalles": [
    {
      "listaPrecioArticuloId": 1,
      "cantidad": 2,
      "porcentajeBonificacion": 0
    }
  ]
}

Cambiar el estado

Enviá EMITIDA para emitir o ANULADA para anular. Podés incluir observaciones.

{ "estado": "EMITIDA" }

Errores

La API devuelve problemas en JSON. 400 indica datos inválidos, 404 un recurso o referencia inexistente y 409 un conflicto con las reglas de facturación.
